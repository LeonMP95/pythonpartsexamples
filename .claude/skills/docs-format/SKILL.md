# Format documentație

## README.md al fiecărui proiect din NewAll
1. Ce face PythonPart-ul (2–3 propoziții)
2. Fișiere (tabel: fișier, rol)
3. Instalare în Allplan și unde se găsește în Library
4. Date de intrare (paleta, formatul fișierelor)
5. Ce se calculează, cu articolele din normă
6. Limitări și ce trebuie verificat de inginer
7. Teste (comanda)

## Ghiduri (`NewAll/docs/`)
- Un subiect per fișier
- Pași numerotați pentru proceduri
- Exemple rulabile

## NewAll/CHANGELOG.md
```
## [Nelansat]
### Adăugat
- <ce>
### Modificat
- <ce>
### Reparat
- <ce>
```

## Stil
- Limba: română (cu diacritice). Codul și comentariile din cod pot fi în română sau engleză, consecvent în fiecare fișier.
- Propoziții scurte, la persoana a doua („rulează”, „deschide”)
- Fără promisiuni despre funcții care nu există
